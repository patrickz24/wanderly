# Documentation

Project documentation beyond the root README. Each document is written at the milestone that
produces its content, so files marked "planned" do not exist yet.

| Document                | Content                                                                                                       | Status                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| [`adr/`](adr/README.md) | Architecture Decision Records: one decision per file, with trade-offs and rejected alternatives.              | Started (milestone 1), grows each milestone              |
| `EVALUATIONS.md`        | Evaluation methodology (retrieval, agent, LLM-as-judge), thresholds, and results generated by `npm run eval`. | Planned (milestone 5)                                    |
| `OBSERVABILITY.md`      | Tracing model in Langfuse, what to look at to diagnose a regression, and a real case met during development.  | Planned (milestone 8, anomaly log kept from milestone 3) |
| `DEPLOYMENT.md`         | Hosting, secrets, deployment and rollback procedure, online dashboards.                                       | Planned (milestone 7)                                    |
| `INTERVIEW_NOTES.md`    | Interview preparation notes, in French: design questions and answers about the project.                       | Planned (milestone 8)                                    |

Related files at the repository root and elsewhere:

- [`SECURITY.md`](../SECURITY.md): vulnerability reporting, security model and data retention.
- [`CONTRIBUTING.md`](../CONTRIBUTING.md): setup, scripts, testing policy, commits and ADRs.
- `data/corpus/ATTRIBUTION.md`: sources and licence of the travel corpus. Planned (milestone 2).

## Conventions

- English, except `INTERVIEW_NOTES.md`.
- Numbers come from running code. Evaluation results are written by the evaluation runner between
  markers in `EVALUATIONS.md`; the methodology around them is written by hand.
- Diagrams use Mermaid so they render on GitHub and stay diffable.
